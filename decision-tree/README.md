# Decision Tree Documentation

This directory contains the mermaid source files and rendered PNGs for the UFO Modeling Decision Tree.

## From Theory to Implementation
Once you have used the decision tree to identify your UFO stereotypes, you can use the **Tonto Skill** for technical implementation:

- **Tonto Technical Guide:** [SKILL.md](../modeling-case/tonto-examples/.github/skills/tonto-ontology/SKILL.md)
- **Syntax & Patterns:** Reference the [Extending Ontologies](../modeling-case/tonto-examples/.github/skills/tonto-ontology/references/extending.md) guide for concrete Tonto code examples.

## File Structure
- `00-Start.mermaid` - Top-level: Individual vs. Universal
- `01-Individual.mermaid` - Instance-level entities and relations
- `02a-Substantial.mermaid` - Types: Kinds, Roles, Phases, Categories, etc.
- `02b-Abstract.mermaid` - Types: Datatypes, Enums
- `03-Moment.mermaid` - Types: Qualities, Modes, Relators
- `04a-Relation.mermaid` - Domain relations (Formal, Material, Part-Whole)
- `04b-Association.mermaid` - Fundamental associations (Characterization, Mediation, etc.)
- `05-Perdurant.mermaid` - Types: Events, Actions, Processes, Activities
- `06-Higher-order.mermaid` - Types: Powertypes, Higher-order types
